# ringfont

Ring validation gates for font inputs before they hit prod.

**Site:** https://theworker02.github.io/ringfont/

## Install / run

```bash
git clone https://github.com/theworker02/ringfont.git
cd ringfont
node src/cli.js
node --test
```
